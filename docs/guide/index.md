# Getting Started

## Installation

```bash
npm install datafilters-typescript
```

## Usage

```typescript
import {} from /* ... */ "datafilters-typescript";
```

## Playground React local

Le repository inclut un playground React (Vite + TypeScript) pour tester le
parseur en local.

Depuis la racine du repo:

```bash
npm run playground:dev
```

Ce script:

- build la librairie TypeScript
- installe les dependances du playground
- lance Vite en mode developpement

Build du playground:

```bash
npm run playground:build
```
